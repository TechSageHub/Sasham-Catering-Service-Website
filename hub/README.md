# Sasham Catering Hub — MVP preview

This folder contains the first interactive dashboard and enquiry-management prototype for Sasham Catering Service.

## Included in this preview
- Responsive business dashboard
- Sample enquiry records and summary counts
- Search and status filtering
- Add-enquiry form
- Status updates, upcoming confirmed events, and follow-up list
- No build step or third-party JavaScript dependency

## Important safety boundary
This is a **front-end prototype only**. It has no authentication, authorization, server, or database. Sample records are fictional and edits persist only in localStorage on the current browser and device; clearing browser data or switching devices can remove or hide them. Do not use it to store real customer, contact, quotation, booking, or payment data. Do not link this preview publicly as a private business portal.

## Before production
1. Confirm the workflow and fields with the business owner.
2. Choose a sustainable no-cost hosting/database plan and verify its current limits.
3. Implement a server-side API, database migrations, secure authentication, authorization, validation, and audit-friendly updates.
4. Connect the public website enquiry form to the API only after the server is secured and tested.
5. Test the complete flow, deploy the private app, then add a business-login link to the public site.
